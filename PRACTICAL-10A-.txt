1. Getting Basic System Information

vi ipadress.sh

	Execute and run
	
3. Setting the hostname
The current hostname can be obtained with
hostname

To set it:
	hostnamectl set-hostname server1.example.com

Verify:
    hostnamectl

Using the shell script
	vi hostname.sh

Execute and run the shell script
